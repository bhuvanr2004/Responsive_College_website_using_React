# 🎓 Edusity – Responsive College Website

A modern and fully responsive college website built using **React.js** and **Vite**. The website provides an attractive user interface with smooth navigation, reusable components, and responsive layouts that work seamlessly across desktops, tablets, and mobile devices.

---

## 📌 Project Overview

Edusity is a front-end educational website designed to showcase a college's information, courses, campus, testimonials, and contact details. The project focuses on responsive web design, clean UI, and component-based architecture using React.

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/your-username/edusity.git
```

### Navigate to Project Folder

```bash
cd edusity
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

Open your browser and visit

```
http://localhost:5173
```
